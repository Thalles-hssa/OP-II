# OP-II
Nesse repositório pretendedo publicar a implementação computacional em python dos cases propostos em aula.

##  Sobre o Projeto

Este repositório contém a resolução computacional do **Case I – Trocadores de Calor (Modelo I)**, desenvolvido como parte extracurricular da disciplina de **Operações Unitárias II** do curso de Engenharia Química da Universidade Federal de São João del-Rei (UFSJ), sob orientação do Prof. Dr. Alexandre Bôscaro França.

O case consiste no dimensionamento térmico de um trocador de calor de **correntes cruzadas** utilizado para refrigeração de um componente eletrônico de alta potência. O objetivo é determinar:

- **(A)** A taxa de transferência de calor entre os fluidos;
- **(B)** A vazão mássica de água necessária;
- **(C)** A área de superfície do trocador.
